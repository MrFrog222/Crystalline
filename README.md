<h1 align="center">Crystalline</h1>
<p align="center">A Meteor Client addon with focus on legit cpvp and general utility</p>

##Features
- Crystal Macro with hit crystal and automatic obsidian placement
- Anchor Macro
- Legit Auto Totem
- Pearl Hotkey
- Block Macro (bind to automatically switch to and place blocks)

##Installation
- Install [Fabric](https://fabricmc.net)
- Install [Meteor Client](https://meteorclient.com)
- Download the [latest release](https://github.com/MrFrog222/Crystalline/releases/latest)  and put it into your mods folder

##Building from source\
Linux `./gradlew  build`\
Windows `./gradlew.bat build`
