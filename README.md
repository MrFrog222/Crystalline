<h1 align="center">Crystalline</h1>
<p align="center">A Meteor Client addon with focus on legit cpvp and general utility</p>

## Features

#### Crystal Macro
Automatically places/breaks crystals with obsidian placement and auto hit
#### Anchor Macro
Automatically places and explodes anchors
#### Legit Auto Totem
Automatically replenishes totems in hotbar and offhand with auto double hand support
#### Pearl Hotkey
Throws a pearl automatically on hotkey
#### Block Macro
Automatically spams blocks on hotkey

## Installation
- Install [Fabric](https://fabricmc.net)
- Install [Meteor Client](https://meteorclient.com)
- Download the [latest release](https://github.com/MrFrog222/Crystalline/releases/latest)  and put it into your mods folder

## Building from source
Linux `./gradlew build`\
Windows `./gradlew.bat build`\
The output will be in `build/libs`
